## 📖 About The Project

**Dodge Arenar** is a minimalist, fast-paced arcade dodging game. The core objective is simple: survive as long as possible against incoming enemy cubes that spawn directly ahead and try to hit you. 

This project was built from scratch as a foundational stepping stone into game development, focusing on mastering movement mechanics, UI timers, script logic, and game loops in Unity.

---

## 🎮 Gameplay & Core Mechanics

* **Player Movement:** Control a green cube smoothly using Unity's built-in `CharacterController` component to move left and right.
* **Survival Objective:** Dodge incoming obstacles. The longer you stay alive, the greater your survival time score.
* **Chronometer System:** Tracks your exact survival time down to the milliseconds.
* **Game Over & Quick Restart:** Colliding with any enemy triggers an instant Game Over screen. Press the **R** key to instantly restart and try to beat your personal best.

---

## 👾 Enemy Types

The game features three distinct enemy variants with unique behaviors:

| Enemy Type | Size | Speed | Description |
| :--- | :--- | :--- | :--- |
| 🛡️ **Tank** | Giant | Very Slow | A massive obstacle that covers more lane space, requiring early positioning. |
| 🟦 **Normal** | Standard | Medium | The baseline challenge with standard speed and proportional size. |
| ⚡ **Small** | Tiny | Very Fast | A bullet-like fast cube that demands rapid reflexes to dodge. |
